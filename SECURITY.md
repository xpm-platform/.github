# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in an xPM Solution project, please report it privately through our [contact page](https://www.xpmsolution.com/contact).

- Do not open a public issue, pull request or discussion about it.
- Describe what you found, where, and how to reproduce it.
- Give us reasonable time to investigate and fix it before sharing it with anyone else.

We will acknowledge your report and keep you informed as we work on it.

## For team members

- Report suspected security issues, exposed secrets or lost devices to the organization owners right away.
- An exposed secret must be revoked and replaced. Deleting the commit is not enough.
- Every pull request uses the checklist in the pull request template. The author completes it before requesting review, and the repository's responsible reviewer confirms it before merging.
