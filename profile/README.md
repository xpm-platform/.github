# xPM Solution

**Integrated Project Controls**
[xpmsolution.com](https://www.xpmsolution.com)

This organization hosts the source code of the xPM platform. Access is limited to authorized team members.

---

## Security rules

Everyone with access to this organization follows these rules.

### 1. Account
- Two-factor authentication (2FA) is mandatory. Prefer a passkey, security key or authenticator app over SMS.
- Keep at least two 2FA methods and store your recovery codes in a safe place.
- Your account is personal. Never share your password, tokens or keys.

### 2. Access
- Access is granted by role and limited to what the job needs.
- Access is reviewed regularly and removed when it is no longer needed.
- Only organization owners approve apps, integrations and third-party access.

### 3. Code and secrets
- Never commit passwords, API keys, tokens, private keys, `.env` files or customer data.
- If a secret is exposed, it must be revoked and replaced. Deleting the commit is not enough.
- Every change goes through a pull request and is reviewed before merge. No direct pushes to main branches.

### 4. Dependencies and automation
- Add only trusted, maintained packages and GitHub Actions. Pin their versions.
- Keep dependencies up to date and act on security alerts.

### 5. Devices
- Work only on devices with disk encryption, a screen lock and current security updates.
- Protect SSH keys with a passphrase.
- Do not copy company code to public repositories, gists, pastebins or unapproved tools.

### 6. Reporting
- Report suspected security issues, exposed secrets or lost devices to the organization owners right away.
- Outside the organization and found a vulnerability? Contact us through our [contact page](https://www.xpmsolution.com/contact). Please do not open a public issue.
